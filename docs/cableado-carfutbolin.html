💾 Firmware — Portería A

⚠️ Conectar el Nano por USB. Subir con Arduino IDE o arduino-cli. Seleccionar placa: Arduino Nano · ATmega328P (Old Bootloader si es clon chino)
/* * RAX CARFUTBOLÍN — Portería A * Arduino Nano V3 + TSOP38438 + LED IR 940nm * Protocolo: READY:A → GOAL:A a 9600 baud */ const byte EMISOR_IR = 3; const byte SENSOR_IR = 7; bool hazAnterior = true; bool listo = true; unsigned long ultimoGol = 0; const unsigned long BLOQUEO_GOL = 700; void configurar38kHz() { pinMode(EMISOR_IR, OUTPUT); // Timer2: ~38kHz por D3 (OC2B) TCCR2A = _BV(COM2B1) | _BV(WGM20) | _BV(WGM21); TCCR2B = _BV(WGM22) | _BV(CS21); OCR2A = 209; OCR2B = 105; } void setup() { Serial.begin(9600); pinMode(SENSOR_IR, INPUT); configurar38kHz(); delay(400); // TSOP: LOW = recibiendo haz IR hazAnterior = (digitalRead(SENSOR_IR) == LOW); Serial.println("READY:A"); } void loop() { bool haz = (digitalRead(SENSOR_IR) == LOW); unsigned long ahora = millis(); // El balón cortó el haz → GOL if (hazAnterior && !haz && listo && (ahora - ultimoGol > BLOQUEO_GOL)) { ultimoGol = ahora; listo = false; Serial.println("GOAL:A"); } // Se rearma cuando el balón sale del haz if (haz) listo = true; hazAnterior = haz; delay(5); }

⚠️ Notas Importantes

✅ CH340 en Windows — Los Nanos clon usan chip CH340. Windows los reconoce como "USB-SERIAL CH340 (COMx)". Si no aparece, instalar driver CH340.
⚠️ Identificar COM — En RAX SOCIAL: COM3 = Portería A, COM4 = Portería B. Si se reconectan, pueden cambiar. Usar etiqueta física en cada Nano.
🔴 No conectar LED sin resistencia — El LED IR sin resistencia de 100Ω quema el LED y puede dañar el pin del Arduino.
⚠️ Old Bootloader — Los Nanos clones chinos suelen usar "Old Bootloader" (optiboot antiguo). Si la subida falla, seleccionar: Processor: ATmega328P (Old Bootloader)
🔌 GND común — Todos los GND deben estar conectados: Nano GND, TSOP GND, emisor 2N2222, y el raíl negativo de la protoboard.
